# Experiment 1: Creating a NumPy Array

## Aim
To demonstrate the creation of various types of NumPy arrays including basic ndarrays, zeros, ones, random arrays, custom matrices, identity matrices, and evenly spaced arrays.

## Required Libraries
- `numpy`

## Execution Command
From the project root folder:
```bash
python experiments/01_numpy_array_creation/main.py
```

## Description & Output
The program initializes different NumPy data structures and displays their contents clearly.

## Result
Successfully created and demonstrated various NumPy array creation methods.
