# Experiment 9: Pickle, Images, Glob, and Databases

## Aim
To perform object serialization with `pickle`, inspect image files with `PIL`, match file patterns using `glob`, and read data from an SQLite database.

## Security Warning
`pickle` module is not secure against erroneous or maliciously constructed data. Never unpickle data received from an untrusted source.

## Required Libraries
- `Pillow`
- Standard modules: `pickle`, `glob`, `sqlite3`

## Execution Command
```bash
python experiments/09_pickle_images_glob_database/main.py
```

## Result
Successfully executed pickle operations, image inspection, glob pattern matching, and SQLite database querying.
